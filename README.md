# ucansogan games — GitHub kullanıcı sitesi

Bu klasördeki dosyalar `karamane/karamane.github.io` adlı **public** reponun köküne konur. Oyun kaynaklarını, .tools klasörünü veya imzalama anahtarlarını bu repoya kopyalamayın.

1. GitHub → + → New repository.
2. Owner: karamane. Repository name: **karamane.github.io**. Visibility: Public.
3. Create repository. Bu klasördeki `index.html`, `app-ads.txt`, `.nojekyll` dosyalarını repo köküne yükleyip commit edin.
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save.
5. GitHub Pages dağıtımı bitince https://karamane.github.io/app-ads.txt adresinin düz metin olarak açıldığını kontrol edin. Tek satır bu klasördeki dosyayla aynı olmalı.

Mevcut https://karamane.github.io/antlix-pages/ sitesi ve gizlilik URL'si aynı kalır. AdMob dosyayı web sitesinin alt klasöründe değil alan adının kökünde arar.

Dosya yayımlandıktan sonra AdMob app-ads.txt doğrulaması ve mağaza bağlantısı ayrıca kontrol edilir. Bir dosyanın hazırlanması veya GitHub'a yüklenmesi, AdMob incelemesinin tamamlandığı anlamına gelmez.

Kaynak: https://support.google.com/admob/answer/9363762
